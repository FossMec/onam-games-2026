# FOSS Onam Games - Design System Prompt

Apply this visual design system to an application. It blends 1990s comic-book print, 1980s Memphis geometry, and Kerala Onam motifs into flat, playful, inked interfaces.

## One-Line Direction

Flat, hand-inked, slightly irregular comic-book UI on warm cream newsprint, using washed pastel-faded festival colours, radial pookalam halftones, and zero drop shadows.

## The Six Rules

1. NO SHADOWS. Depth comes from ink outline weight, flat colour blocking, and halftone dots only. Never a blurred drop shadow.
2. HALFTONE IS A POOKALAM. Ben-Day dots laid out in radial flower-carpet symmetry, not square grids.
3. MEMPHIS DECOR IS SECRETLY ONAM. Zigzag = vallam (snake boat), concentric rings = pookalam, half-circle = muthukuda (umbrella), blob = banana leaf, squiggle = coconut palm, diamond = festival kite.
4. EVERYTHING IS INKED. One warm near-black outline on every box, button, badge, and motif. Never grey hairlines.
5. SOOTHING PASTEL, NEVER NEON. All colours sit in the same pastel-faded lightness range and clash harmoniously.
6. TILT IS PUNCTUATION. 1-3 degrees on stickers, badges, bursts. Never tilt boards, timers, grids, or leaderboard rows.

## Palette

- paper: #FBF3E4 (newsprint cream, the page)
- paper-2: #FFFCF5 (raised panel)
- paper-3: #F0E4CC (sunken / muted fill)
- ink: #22202B (warm near-black, all outlines & glyphs)
- ink-soft: #6B6478 (secondary copy)
- pop-red: #F2695C (energy, errors, Maveli's face)
- pop-yellow: #F5C443 (celebration, highlights, crown)
- pop-teal: #5FBFA8 (brand, safe states, open source)
- pop-blue: #7B9BE0 (information, calm structure)
- pop-pink: #E48BB4 (petals, playful emphasis)
- pop-purple: #9C82D4 (mystery, supporting rings)

Use 2-4 accents per screen, one dominant. Ink anchors, cream breathes.

## Typography

- Bungee: wordmark only
- Baloo Chettan 2: headings, buttons, labels
- Nunito: body text
- Space Mono: numbers, timers, scores
- Bangers: comic shouts / onomatopoeia
- Caveat: sarcastic margin asides
- Kalam: royal letters / proclamations

## Shapes

- Panels: softly rounded, thick ink border, optional coloured strip on top edge
- Stickers: uppercase, outlined, slightly rotated, look slapped on
- Badges: pill-shaped outlined markers, tidy
- Starbursts: irregular spikes, hand-drawn feel
- Buttons: flat inked blocks, sink 2px on press with halftone wash
- Cursor: a muthukuda umbrella (resting -18deg, pointing -38deg, grabbing +24deg)

## Motifs

- Pookalam: radial, layered concentric rings with alternating pastel bands and repeated petals
- Vallam: long low zigzag or red hero boat
- Muthukuda: half-circle canopy + stem
- Banana leaf: friendly blob
- Palm: loose winding squiggle
- Maveli: round belly, red face, moustache, yellow crown, cheerful

## Mood Colours

triumph=yellow, great=teal, decent=blue, mid=purple, fail=red, confused=pink.

## Never

Gradients as primary form language, drop shadows, glassmorphism, neon/glossy/3D, dark mode, photorealistic scenery, stock festival clip-art, generic POW/BAM cliches, sterile perfect geometry, dense noise that competes with content.

## Confetti

Sparse Memphis scatter that encodes Onam (zigzag vallam, pookalam rings, muthukuda, leaf blob, palm, kite, dot clusters). Vary size/rotation/position. Behind content, never over buttons or text.
